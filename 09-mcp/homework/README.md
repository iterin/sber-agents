## 🎯 Описание задания

В этом задании вы познакомитесь с Model Context Protocol (MCP) — современным стандартом от Anthropic для расширения возможностей LLM. Вы запустите готовый MCP сервер с банковскими инструментами, протестируете его работу с агентом и добавите свой собственный инструмент.

4. **Ключевые концепции:**

**Model Context Protocol (MCP):**
- Стандартный протокол для подключения инструментов к LLM
- Инструменты работают как отдельный сервер (не в коде агента)
- Один MCP сервер можно использовать с разными клиентами

**Преимущества MCP:**
- 🔌 **Переиспользование** — один сервер для многих клиентов
- 🔒 **Изоляция** — инструменты работают отдельно от агента
- 🌐 **Стандартизация** — единый протокол для всех

        float,
        Field(

## Важные указания по реализации MCP сервера:

- Для реализации MCP сервера подготовь подпроект в папке mcp/mcp-bank-agent, по аналогии с референс проектом docs/references/mcp/mcp-http. Данные по продуктам храни в подпроекте в data/bank_products.json - сгенерируй данные сам и пусть они там будут статические (не надо писать скрипт sample_data как в референсе), используй для генерации поиск информации о продуктах СБЕРА с его офф сайта

- MCP сервер должен запускаться как streamable-http на порту 8000 (порт по умолчанию для FastMCP).

- Для запуска MCP сервера используй uv pyproject.toml, команду запуска добавь в наш общий Makefile головного проекта

- currency_converter реализация: инструмент должен поддерживать универсальную конвертацию ЛЮБОЙ валюты в ЛЮБУЮ через RUB как промежуточную валюту. Используй API cbr-xml-daily.ru (JSON обертка над официальным ЦБ РФ)

## Важные указания по подключению MCP инструментов через клиента к агенту:

- Опирайся на референсную тетрадку docs/references/agent-mcp.ipynb (раздел 9. Агент с MCP инструментами)
- КРИТИЧНО: create_bank_agent() и initialize_agent() ДОЛЖНЫ быть асинхронными (async def), так как MultiServerMCPClient.get_tools() это async метод и их вызовы тоже должны быть с await
- Graceful degradation: Агент должен пытаться подключиться к MCP серверу, но если не удалось - логировать warning и продолжать работу БЕЗ MCP инструментов (только с базовым rag_search). Это позволяет боту работать даже если MCP сервер не запущен
- Для получения инструментов от MCP клиента используй: mcp_tools = await mcp_client.get_tools()
- В главный pyproject.toml добавь зависимость: langchain-mcp-adapters>=0.1.0

## Важные указания по запуску:
