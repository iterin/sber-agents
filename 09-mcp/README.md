# Модуль 9. Model Context Protocol (MCP)

## Описание

Знакомство с Model Context Protocol (MCP) — современным стандартом от Anthropic для расширения возможностей LLM через интеграцию с внешними системами и инструментами. Вы узнаете как работает MCP, как он меняет подход к созданию инструментов для агентов, и как интегрировать существующие MCP-серверы в ваши приложения.

- MCP-серверы: ресурсы, инструменты, промпты
- Экосистема MCP: готовые серверы и коннекторы
